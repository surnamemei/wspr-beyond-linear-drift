# IEEE Access LaTeX template audit

- Official source: [IEEE Access, Preparing Your Article](https://ieeeaccess.ieee.org/authors/preparing-your-article/), LaTeX download linked on the author page.
- Direct template ZIP: <https://ieeeaccess.ieee.org/wp-content/uploads/2026/05/ACCESS_latex_template_20260513-1-1.zip>.
- Inspected on 2026-09-25. ZIP root: `ACCESS_latex_template_20260513/`; `access.tex` identifies an adjustment on 2026-05-13 to the author byline. No other version identifier was supplied in the archive.
- Class: `\documentclass{ieeeaccess}`, backed by the bundled `IEEEtran.cls`. The Access class, style, logo, font/map files, and `IEEEtran.bst` in this directory were copied from that ZIP, without editing the official files.
- Template packages include `cite`, `amsmath`, `amssymb`, `amsfonts`, `algorithmic`, `graphicx`, `textcomp`, and `bm`. This manuscript uses the subset it needs plus `booktabs` and `xurl` for existing tables and the repository URL.
- Author format: `\author{...\authorrefmark{1}}`, `\address[1]{...}`, and `\corresp{...}`. The source names Jinghang Mei and the supplied University of Sydney affiliation and email. The official class has no ORCID display macro; the confirmed ORCID is stored in source comments and submission metadata for portal entry.
- Biography: `IEEEbiographynophoto` below the references; submission-stage biographies are required for every author. No photo is used.
- Acknowledgment: unnumbered `Acknowledgment` section, before references, carrying the AI-use disclosure and identification of affected manuscript content.
- References: `IEEEtran.bst` with BibTeX; the verified 13 records are preserved.
- Headings: numbered Access/IEEEtran section and subsection commands; unnumbered Data and Code Availability and Acknowledgment.
- The distributed class hard-codes sample `VOLUME 11, 2023` footer text and a `Digital Object Identifier` label. Its `\vol{}` and `\year{}` commands replace values but cannot suppress the literal `VOLUME` footer; `\doi{}` clears a value but cannot suppress the label. No official submission-only switch or ORCID display command was found in the supplied class. The class remains unmodified and no article publication volume, year, or DOI has been invented. The separate Zenodo DOI in Data and Code Availability and `CITATION.cff` identifies the archived software/data release only; it is not assigned to `\doi{}`. The PDF therefore still visibly contains the class-provided sample placeholders; an IEEE-approved submission-stage override or production instruction is needed before it can be described as free of false publication metadata.
- The confirmed author ORCID is `https://orcid.org/0009-0007-2901-3285` in the LaTeX source comment, `submission_metadata.md`, and root `CITATION.cff`. The confirmed corresponding email appears in `\address` and `\corresp` and in the rebuilt PDF.
- IEEE Access [submission guidelines](https://ieeeaccess.ieee.org/authors/submission-guidelines/) require AI-generated-text disclosure in the Acknowledgment and an AI-system citation in affected sections. The brief Introduction footnote is retained as the in-text pointer; the full systems, scope, assistance level, and author responsibility remain in Acknowledgment.
