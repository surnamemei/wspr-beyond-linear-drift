# IEEE Access submission checklist

Based on the [current official submission guidelines](https://ieeeaccess.ieee.org/authors/submission-guidelines/) and [post-acceptance guide](https://ieeeaccess.ieee.org/authors/post-acceptance-guide/). Checked items are evidenced by the current source/build; unchecked items need author or production action.

- [x] Official IEEE Access template used (2026-05-13 ZIP; see `template_audit.md`).
- [x] LaTeX source provided in an independent Access directory.
- [x] PDF built from `paper/access/main.tex` with local figure and BibTeX files.
- [x] Source and PDF files individually below 40 MB.
- [x] Jinghang Mei appears in source and PDF.
- [x] Supplied University of Sydney affiliation appears in source and PDF.
- [x] Corresponding author identified.
- [x] University of Sydney email confirmed and substituted for the explicit placeholder.
- [x] ORCID confirmed and stored in LaTeX source metadata and `CITATION.cff`.
- [ ] ORCID associated with the submission account; public/profile-population status confirmed in the portal.
- [x] Factual no-photo biography included after the references.
- [x] AI disclosure included in Acknowledgment; ChatGPT and Codex identified and types/sections of assistance stated. The brief Introduction footnote remains as the requested in-text AI-system citation.
- [x] Manuscript prose and reference layout reviewed for conspicuous rendering defects.
- [x] Existing 13 bibliography records preserved, with proper-name capitalization protected in the copied BibTeX.
- [ ] Author to reconfirm live retraction status of all references immediately before submission.
- [ ] Author to confirm manuscript is not under review elsewhere.
- [x] Six keywords in the required 3--10 range.
- [x] Research Article selected in `submission_metadata.md` for portal entry.
- [x] Data/code availability statement includes the public repository and verified Zenodo software/data archive DOI; the IEEE article DOI remains unassigned.
- [x] All seven figure environments and five table environments retained and cross-referenced.
- [ ] First-use abbreviation audit needs author confirmation against final PDF.
- [x] No unresolved citations, undefined labels, or missing figures in the final build.
- [ ] No overfull-box warnings: official class emits the same title/output-routine warnings in its distributed sample. Visual rendering must be reviewed with the journal/author for acceptability.
- [x] Page count below the journal's recommended 20 pages.
- [ ] Class-provided sample `VOLUME 11, 2023` footer and blank DOI label to be resolved through an approved submission-stage format/production instruction; the supplied class has no safe suppression switch.
- [ ] Final submission-portal metadata, ORCID association, exclusivity, and any required declarations to be completed by the author.
