# Historical development artifacts

These files preserve early forensic reports, one-off drift checks, a noiseless smoke script, an experiment backup, and an empty debug placeholder. They are not imported by active code, referenced by documented reproduction commands, or used to produce the manuscript's reported results. Some contain superseded implementation assumptions or incomplete checks; do not use them as current validation evidence.

The validated experiment definitions and tests remain in `experiments/`, `scripts/`, `src/`, and `tests/`. This archive is retained for provenance, not for routine execution.
